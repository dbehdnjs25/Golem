# Temple compass icons

Five 32x32 replacement temple detectors, generated with built-in image_gen.
Round pocket compasses with bronze housing, dial ticks and a two-ended needle;
no handle or stem. Biome colors: amber, ice blue, sage mint, olive, sandy gold.

prompts.json records the prompts. source/ contains original renders.
final32/ contains the editable monochrome-layer Aseprite files and PNG exports.
backup/ preserves the previous detector assets. preview.png shows all five.
prepare.py exports through native Aseprite; install.py validates all layers,
installs only these five icons, and rebuilds the shared icon atlas and preview.
Runtime filenames remain unchanged; src/ and tiles32/ are untouched.
