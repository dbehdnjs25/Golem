# UI assets

The hotbar uses `hotbar_slot.png` and `hotbar_slot_selected.png`, with `hotbar_preview.png` showing the transparent five-slot composition. The health bar pairs a pink framed 20px heart square with a connected gauge; `health_heart.png` and `health_bar_preview.png` show its pixel art.

Run `.venv/Scripts/python.exe assets/ui/build.py` to regenerate the PNG assets. Open `index.html` in Orca to browse the local UI asset shelf.
