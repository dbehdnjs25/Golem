# UI assets

`hotbar_slot.png` and `hotbar_slot_selected.png` are the runtime-ready carved-stone hotbar sockets. `hotbar_preview.png` shows the five-slot composition on transparency, without a backing plate.

Run `.venv/Scripts/python.exe assets/ui/build.py` to regenerate the hotbar PNGs. Open `index.html` in Orca to browse the local UI asset shelf.
