# UI assets

`hotbar_panel.png`, `hotbar_slot.png`, and `hotbar_slot_selected.png` are the runtime-ready five-slot HUD pieces. `hotbar_preview.png` is the composed art preview.

Run `.venv/Scripts/python.exe assets/ui/build.py` to regenerate the PNGs. Open `index.html` in Orca to browse the local UI asset shelf.
