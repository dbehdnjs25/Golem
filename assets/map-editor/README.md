# Meadow Studio

`index.html`을 더블클릭하면 열리는 오프라인 맵 에디터입니다. HTML 하나에 타일과 코드를 포함하므로 서버와 설치가 필요 없습니다.

- **새 맵**에서 초원·늪지·불탄 숲·바람 고원·황무지·설원 중 바이옴을 선택합니다. 선택은 맵 이름 옆에 표시되고 JSON 및 자동 저장에 포함됩니다. 크기 변경·랜덤 배치·실행 취소에서도 유지됩니다. 초원은 64종, 늪지는 기본 땅과 변형 16종, 불탄 숲은 기본 땅과 변형 16종을 선택할 수 있습니다. 나머지 바이옴은 타일 목록과 선택 미리보기가 비어 있으며, 그리기·추출·랜덤 배치는 비활성화됩니다. 맵 저장·불러오기·크기 변경·화면 이동은 사용할 수 있습니다. 이전에 초원 타일을 공통 사용하던 늪지 맵은 불러올 때 늪지 기본 땅으로 전환됩니다.
- JSON의 `biome`은 게임과 같은 식별자(`grassland`, `bog`, `burnt_forest`, `wind_plateau`, `wasteland`, `snowfield`)를 사용합니다. 바이옴이 없는 기존 맵은 초원으로 불러옵니다.

- 왼쪽 위 **전체 랜덤 배치** 버튼은 현재 맵 전체를 새로 채웁니다. 잔디를 약 65% 남기고 꽃·풀·클로버·돌과 혼합 타일을 섞습니다. 검색·카테고리와 무관하게 전체 타일을 사용하며, Ctrl+Z 한 번으로 이전 맵을 복구할 수 있습니다.

- 왼쪽 카테고리(전체 / 잔디·풀 / 한 송이 꽃 / 꽃 무리 / 돌 / 혼합 / 전체 랜덤)와 검색으로 타일을 고르고 드래그해 그립니다.
- 꽃 종류별 기본 타일과 랜덤 배치 변형을 묶어 표시합니다. 한 송이 꽃은 4종, 꽃 무리와 혼합 들꽃은 3종의 랜덤 배치가 있습니다. 총 64종입니다.
- 전체 랜덤 배치 4종은 서로 다른 색의 꽃과 풀·클로버·돌을 함께 섞습니다. 각 장식을 따로 배치하며 서로 겹치지 않습니다. 기존 꽃과 조약돌 조합(15, 45~47번)을 대체하므로 저장된 맵에서 해당 칸도 전체 랜덤 배치로 표시됩니다.
- 잔디·풀 카테고리의 클로버에는 1·2·3·5개를 흩뿌린 랜덤 변형 4종(48~51번)이 있습니다.
- 돌 카테고리에는 작은 조약돌·조약돌 두 개·작은 돌무리마다 랜덤 변형 4종씩(52~63번)이 있습니다. 돌무리는 큰 돌과 작은 돌을 섞어 각 돌을 독립적으로 배치합니다. 전체 랜덤 배치 버튼에서도 새 변형을 사용합니다.
- 랜덤 배치는 에셋 생성 시 고정 시드로 정합니다. 같은 타일은 다시 열거나 빌드해도 같은 모습이며, 이전 방향별 변형(16~47번)은 랜덤 배치로 바뀝니다.
- 브러시 B / 사각형 R / 영역 채우기 F / 기본 잔디로 지우기 E / 스포이트 I / 화면 이동 H.
- Space + 드래그로 이동, 휠로 확대·축소, 우클릭으로 타일을 추출합니다.
- Ctrl+Z 실행 취소, Ctrl+Shift+Z 다시 실행, Ctrl+S JSON 저장. 최대 80개 작업을 되돌립니다.
- 브라우저 로컬 저장소에 자동 저장합니다. 안정적인 보관과 다른 컴퓨터 이동에는 JSON 다운로드를 사용하세요.
- JSON 불러오기, 새 맵, 크기 변경도 실행 취소할 수 있습니다. 크기 변경은 왼쪽 위를 기준으로 유지합니다.
- WebP 내보내기는 격자와 편집 표시를 제외한 원래 해상도의 맵 이미지입니다. 브라우저 WebP 인코더의 최고 품질 설정이며, 타일 원본의 무손실 WebP와는 별개입니다.

## 맵 데이터

JSON의 `data`는 왼쪽 위부터 행 우선 순서로 저장한 타일 ID입니다. 초원은 0~63, 늪지는 0~15, 불탄 숲은 0~18를 사용하며 `tileset` 경로는 바이옴의 시트를 가리킵니다. `(x, y)`의 타일은 `data[y * width + x]`입니다. 타일 크기는 32px이며 `tileset`은 이 에디터 폴더 기준의 프로젝트 시트 경로입니다. 파일 위치를 바꾸더라도 에디터는 내장 타일을 사용합니다.

이 에디터는 시각적인 지형 배치 데이터를 만듭니다. 기존 게임의 원형 월드/바이옴 생성기에는 자동 적용하지 않습니다. 충돌·자원·스폰 데이터는 포함하지 않습니다.

Pygame에서 타일을 그리는 예시:

```python
import json
from pathlib import Path
import pygame

data = json.loads(Path('my-map.json').read_text(encoding='utf-8'))
atlas = pygame.image.load('assets/grassland/tiles32/grassland-32.webp')
for i, tile_id in enumerate(data['data']):
    source = pygame.Rect((tile_id % 4) * 32, (tile_id // 4) * 32, 32, 32)
    screen.blit(atlas, ((i % data['width']) * 32, (i // data['width']) * 32), source)
```

## 수정 및 검증

소스는 `editor.template.html`, `editor.css`, `editor.js`, `model.js`입니다.

```powershell
.venv/Scripts/python.exe assets/grassland/build_tiles32.py
.venv/Scripts/python.exe assets/bog/build_tiles32.py
.venv/Scripts/python.exe assets/burnt-forest/build_tiles32.py
.venv/Scripts/python.exe assets/wind_plateau/build_tiles32.py
.venv/Scripts/python.exe assets/map-editor/build.py
node assets/map-editor/model.test.cjs
node assets/map-editor/editor.biomes.test.cjs
```

늪지 타일은 기본 물 1종과 잔물결·물 위 이끼·개구리밥·갈대·떠 있는 나뭇가지의 랜덤 위치 변형 3종씩으로 구성됩니다. 기본 땅 / 물결 / 수생 식물 / 부유물 카테고리에서 선택하며, 전체 랜덤 배치에도 포함됩니다. 모든 변형은 기본 물과 같은 4px 가장자리를 유지합니다.

불탄 숲은 재 바닥과 탄 나뭇가지 6종·숯 조각 3종·남은 불씨 3종, 불씨 1개·2개 변형 각각 3종을 포함하여 총 19종입니다. 새 에셋은 assets/burnt-forest/tiles32에 있습니다. 바이옴 키는 burnt_forest이며 이전 volcano 맵도 배치를 유지하여 새 에셋으로 열립니다.

불씨 카테고리에서 불씨 1개와 불씨 2개 그룹을 선택할 수 있습니다. 각 그룹에 위치가 다른 변형 3종(ID 13~18)이 있으며, 기존 타일은 유지됩니다.

불씨 3개 타일은 제거했습니다. 선택 가능한 타일은 총 16종이며 불씨는 1개·2개짜리 각 3종만 표시됩니다. 이전 ID 10~12는 호환용으로 예약되어 목록·랜덤 배치에서 제외되고, 불러올 때 2개짜리 ID 16~18로 변환됩니다.

불씨 2개 변형을 3종 더 추가했습니다(ID 19~21). 현재 불씨 1개는 3종, 2개는 6종이며, 불탄 숲의 선택 가능한 타일은 총 19종입니다.

바람 고원은 기본 땅과 바람에 눕는 풀·자갈·풍화된 바위·바람에 깎인 땅·풀과 자갈 혼합의 위치 변형 3종씩, 총 16종(ID 0~15)을 사용합니다. 새 맵에서 바람 고원을 선택하면 전용 타일 목록과 랜덤 배치를 사용할 수 있습니다. 과거 초원 시트를 사용하던 바람 고원 맵은 전용 기본 땅으로 전환됩니다. 에셋은 assets/wind_plateau/tiles32에 있습니다.
