# Desert ground tile

This set contains one opaque, seamless 32x32 sandy ground tile. There are no
decorations or tile variants; the map renderer repeats this base tile.

- `tiles32/desert-preview.png`: nearest-neighbour enlarged preview.
- `tiles32/desert-32.aseprite`: editable Aseprite source.
- `tiles32/tileset.json`: runtime and map-editor tile definition.

Rebuild with `.venv\Scripts\python.exe assets/desert/build_tiles32.py`.
