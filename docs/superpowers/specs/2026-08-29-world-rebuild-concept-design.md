# 컨셉 재설계 — 설계 스펙

_작성일: 2026-08-29 · 프로젝트: Golem (pygame-ce)_

## 목표

핵심 루프는 그대로 두고 컨셉과 세부 시스템을 전부 교체한다.

유지하는 루프:

```
자원을 캔다 → 소지 한계 때문에 돌아온다 → 거점을 지킨다 → 반복 → 최종 결전
```

버리는 것: 컴퓨터/파일시스템 테마 전체. 2단 MB 저장소, 핫바 해금, 파일 탐색기
스타일 인벤토리, "Defrag" 제목, 바이러스·트로이 명명 — 전부 대체한다.

기존 코드 중 살아남는 것은 **구조**다. 순수 `update(dt, ...)` / `draw(surface)` 분리,
고정 타임스텝, frozen dataclass 카탈로그 패턴, 씬 스택. 데이터와 이름은 전부 바뀐다.

## 세계

세계는 **이미 한번 멸망했다.** 플레이어는 폐허에서 깨어난다. 코어를 되살리고,
다섯 보스를 꺾고, 마지막 습격을 버텨 세계를 복구하는 것이 목표다.

## 시작 — 코어 점화

- 맵 **정중앙의 받침** 바로 옆에서 스폰. 주변에 **코어 파편**이 흩어져 있다
- 파편을 모아 코어를 조합하고, **플레이어가 직접 받침에 올려놓는다** → 그 순간이 1일차
- 점화 전에도 낮/밤은 흐르고 야생동물이 위협이 된다

점화를 하드 게이트로 막지 않는다. 대신 **회복 수단이 결계 안에만 있으므로**, 코어를
세우지 않으면 다친 채로 버틸 수가 없다. 강제가 아니라 압력이다. 그리고 언제 시작할지를
플레이어가 정하게 된다.

## 맵 구조

- **중앙 원형 초원** — 반지름 36,000(걸어서 3분). 기본 바이옴
- **바깥 링도 같은 두께** — 36,000. 맵 반지름은 72,000(걸어서 6분).
  넓이로는 초원이 1/4, 링이 3/4다 — 바깥쪽 띠가 안쪽 띠보다 훨씬 넓기 때문이다
- **바깥 도넛 링을 5등분** — 각각 다른 바이옴, 다른 위험도·지형·자원
- **코어에서 멀어질수록** 골렘이 강해지고, 나무·광맥 분포가 늘고, 좋은 광물이 나온다
- 정오각형 꼭짓점 방향으로 바이옴마다 **보스 사원 1개**. 위치는 그 바이옴 안에서
  랜덤이되, 안쪽/바깥쪽 끝에는 생성되지 않는다 (보기 좋게 여백을 둔다)

바이옴이 곧 난이도 등급이고, 같은 바이옴 안에서도 거리가 멀수록 어렵다.

### 다섯 바이옴

| 순서 | 바이옴 | 지형 | 속성 | 재료 | 보스 기믹 = 최상위 마법 |
|---|---|---|---|---|---|
| 1 | 화산지대 | 용암이 길을 막는다 (보이는 위험) | 불 | 흑요석 | 지나간 자리가 계속 탄다 |
| 2 | 설원 | 눈보라로 시야가 짧다 | 얼음 | 서리 결정 | 맞은 대상이 잠깐 멈춘다 |
| 3 | 바람 고원 | 좁은 능선과 절벽, 밀리면 떨어진다 | 바람 | 풍화석 | 강하게 밀어낸다 |
| 4 | 늪지 | 질척여서 느려진다 | 독 | 늪 이끼 | 웅덩이를 남긴다 — 밟으면 스테미나가 마른다 |
| 5 | 황무지 | 넓고 평평해 숨을 데가 없다 | 번개 | 뇌석 | 표식을 찍고 표식끼리 전기가 튄다 |

순서는 난이도 순이다. 다섯 바이옴은 모두 같은 링 위에 있어서 거리로는 구분되지 않는다.
**난이도 차이는 보스와 지형에서만 나온다.** 어느 방향에 어느 바이옴이 배치되는지는
게임마다 랜덤이다.

배치 이유:

- **속성 다섯 개의 기능이 겹치지 않는다.** 불은 땅을 막고, 얼음은 멈추고, 바람은
  밀어내고, 독은 스테미나를 깎고(이미 있는 시스템 재활용), 번개는 여럿을 동시에 친다.
  색만 다른 데미지가 아니라 쓰는 상황이 다르다
- **지형도 겹치지 않는다.** 정적 위험(용암) / 시야 제한(눈보라) / 낙하(절벽) /
  이동 저하(늪) / 엄폐 없음(황무지). 다섯 곳에서 움직이는 방식이 각각 다르다
- **화산이 1번인 이유** — 용암은 눈에 보이고 움직이지 않는 위험이라 가장 읽기 쉽다
- **늪지가 4번인 이유** — 스테미나가 마르는 기믹은 요리·물약이 갖춰지기 전에 만나면
  대응 수단이 없다. 뒤로 미루면 "준비하고 가는 보스"가 된다
- **번개가 5번인 이유** — 습격은 결국 떼로 온다. 여럿을 한 번에 훑는 마법이 최종 습격
  5번의 답이다. 3번에서 얻은 밀어내기와 이어져 `밀어서 모은다 → 한 번에 훑는다`가 된다

보스전이 곧 마법 튜토리얼이다. 그 기믹에 당해본 다음 같은 기믹을 손에 넣는다.

초원은 속성이 없다. 기초 마법만 나온다.

## 코어와 결계

코어 강화가 주는 것은 세 가지뿐이다.

| | 내용 |
|---|---|
| 결계 반경 | 골렘이 못 들어오는 안전 반경. 최대치도 초원 반경보다 훨씬 작다 |
| 결계 안 회복 | HP 자연 회복은 **결계 안에서만**. 필드에는 회복이 없다 |
| 건축 공간 | 제작대·용광로·화덕·고로는 **결계 안에만** 설치 가능 → 반경이 곧 지을 자리 |

결계를 넓혀도 **땅이 초원으로 복구되지는 않는다.** 영역만 넓어진다.

전진 기지는 만들 수 없다. 코어가 유일한 거점이다.

## 하루와 습격

- **평소 밤** — 골렘은 결계 안에 못 들어온다. 대신 **야생동물이 결계 주변에 몰려**
  파밍하러 나가는 길을 성가시게 한다
- **습격 밤** — 결계가 뚫리고 골렘이 코어로 몰려온다

**주기는 레벨 캡을 따라간다.**

| 잡은 보스 | 습격 주기 |
|---|---|
| 0 | 7일 |
| 1 | 6일 |
| 2 | 5일 |
| 3 | 4일 |
| 4 | 3일 |
| 5 | 2일 |

**구성도 같은 원인에서 나온다.** 어떤 바이옴의 보스를 잡으면 그 바이옴의 골렘이
습격에 합류한다. 즉 난이도가 달력이 아니라 **플레이어의 진행도**를 따라간다.
별도의 난이도 수치가 필요 없고, "강해진 대가로 밤이 잦고 험해진다"로 읽힌다.

## 자원과 제작

### 등급 사다리 — 초원

```
채굴:  돌 → 구리 → 철 → 금        + 아연 (초원 바깥쪽 희귀, 주조 전용)
채집:  나무 → 화덕에서 숯

주조:  구리 + 아연 = 황동          (용광로)
       철   + 숯   = 강철          (고로)

도구 등급:  돌 → 구리 → 철 → 금 → 황동 → 강철
```

- **아연은 도구 등급이 아니다.** 황동을 만드는 재료로만 쓰인다. 초원 바깥쪽에서만
  나오므로, 황동이 금보다 윗 등급인 값을 거리로 치른다
- **고로**는 자리를 많이 차지해서 **결계가 일정 반경 이상**이어야 지을 수 있고,
  건설에 **황동**이 든다. 즉 최고 등급인 강철이 **코어 레벨에 묶인다**
- **화덕**은 고기를 굽는 곳이자 나무를 숯으로 굽는 곳이다. 건물이 늘지 않는다

강철에 도달하는 줄:

> 코어를 올려 결계를 넓히고 → 초원 바깥에서 아연을 캐 황동을 만들고 → 그 황동으로
> 고로를 짓고 → 나무를 구워 숯을 만들고 → 철을 잔뜩 캔다.

### 장비

- **무기** — 단검, 장검, 검, 창, 활, 지팡이 등
- **채집 도구** — 곡괭이, 삽, 괭이, 도끼 등
- **배낭** — 착용해서 인벤토리 칸을 늘리는 장비. 등급을 올리면 칸이 더 는다
- **갑옷은 없다**

### 제작 시설 (전부 결계 안)

제작대 · 용광로 · 화덕 · 고로

## 마법 — 그림을 찾아 새긴다

바이옴 재료는 등급을 올리지 않는다. 대신 마법에 쓰인다. **등급(초원)과 속성(바이옴)은
서로 섞이지 않는 두 개의 사다리다.**

획득처가 다섯 단계다.

| 위치 | 수호 | 마법 |
|---|---|---|
| 초원 작은 구조물 | 없음 | 기초 |
| 초원 큰 구조물 | 골렘 | 기초와 기믹 동일, 더 강함 |
| 바이옴 작은 구조물 | — | 그 바이옴 기초 |
| 보스 사원 상자 | — | 그 바이옴 상위 |
| **보스 처치** | — | 그 바이옴 최상위, **그 보스의 기믹을 따름** |

규칙:

- 그림은 **영구히 배운다**. 하지만 새기려면 **새김 도구**를 제작해야 하고, 도구는
  **3회 쓰면 파괴**된다. 그래서 "이 그림을 이 장비에 새기는 게 맞나"가 매번 판단이 된다
- **마법마다 새길 수 있는 장비가 다르다.** 예: 신속은 무기에만, 불은 무기와 지팡이 양쪽
- **속성 칸 수는 업그레이드로 늘린다** (고정 1칸이 아니다)
- **지팡이**는 자체 공격이 없고 새긴 그림이 곧 마법이다. 위력이 셀수록 부담이 쌓이고,
  **과부하되면 일정 시간 사용 불가**
- 각 바이옴 재료로 **탐지기**를 만들면 그 바이옴 사원의 **방향과 대략적 거리**를 알려준다.
  좌표는 주지 않는다 — 랜덤 배치의 의미를 남기기 위해서다

바이옴 순회를 강제하는 것은 상성표가 아니라 **그림이라는 눈에 보이는 수집품**이다.
숨은 데미지 표를 밸런싱할 필요가 없다.

## 적

| 분류 | 행동 |
|---|---|
| **골렘** | 코어를 노린다. 코어에서 멀수록 강하다. 습격 밤에 몰려온다 |
| **보스 골렘** | 사원을 지킨다. 5마리, 기믹과 난이도는 「다섯 바이옴」 표 참조 |
| **야생동물** | 늑대·토끼 등. 밤에 결계 주변에 몰린다. 재료만 준다 |

보스끼리 기믹을 흡수하지 않는다. 대신 **플레이어가** 보스의 기믹을 최상위 마법으로
가져간다.

## 생존

- **HP** — 결계 안 자연 회복(공짜, 느림) 또는 **물약**(즉시, 재료가 귀함).
  물약은 필드에서 쓸 수 있지만 유한하다. 그래서 귀환은 "치료"가 아니라 "보급"이 된다
- **스테미나** — 회피·달리기·채집에 소모. **고기로 회복**
  - 익힌 고기: 스테미나만 회복
  - **날고기: HP를 깎고** 스테미나만 회복 → 급할 때 대가를 치르는 선택지
  - 굽는 것은 결계 안 화덕에서만 → 귀환 이유가 하나 더
- **배고픔 시스템은 없다**

## 소지품

**무게 시스템은 없다.** 한계는 칸 수다.

| | 내용 |
|---|---|
| **핫바** | 5칸. 바로 꺼내 쓰는 것 |
| **인벤토리** | 기본 소지 칸 |
| **배낭** | 제작해서 착용. 칸을 추가. 등급을 올리면 칸이 더 는다 |

UI는 슬롯 격자(마인크래프트식)다. 예전의 MB 목록형 파일 탐색기는 버린다.

귀환 이유는 세 가지다 — 칸이 참 / HP가 닳음(회복은 결계 안) / 제작 시설이 결계 안에만 있음.

## 죽음

| 유지 | 떨어뜨림 |
|---|---|
| 핫바 5칸 (무기·도구 포함) | 인벤토리 **모든 칸이 각각 개수의 절반** |
| | **배낭** (안에 든 것 통째로) |

- 절반이 나누어떨어지지 않으면 **떨어뜨리는 쪽을 올림**한다.
  `32 → 16 떨굼/16 유지`, `7 → 4 떨굼/3 유지`, `1 → 1 떨굼/0 유지`
- 1개짜리도 떨어진다. 새김 도구나 보스 아이템을 지키려면 **핫바에 올려둬야 한다** →
  핫바 5칸을 무엇으로 채울지가 계속 판단거리가 된다
- **배낭을 잃으므로 회수하러 갈 때는 칸이 줄어든 상태**다. 한 번 죽으면 회수 원정
  자체가 빡빡해진다
- **부활은 코어 받침 옆**
- **짐 더미는 한 번에 하나만** 남는다. 회수 전에 또 죽으면 이전 것은 사라진다.
  시간 제한 없이도 즉시 회수 압력이 생기고, 실수 한 번은 용서받는다

## 승리 흐름

```
자원 채집 → 코어 강화 → 레벨 캡 도달
  → 보스 처치 → 캡 +1 → 다시 강화 …  (×5)
  → 최종 강화 → 2일 주기 습격 5번 버티기 → 최종 습격 → 승리
```

보스를 잡으면 나오는 아이템이 코어 레벨 캡을 하나 올린다. 캡이 오를 때마다 습격
주기가 하루씩 짧아지고, 그 보스 바이옴의 골렘이 습격에 합류한다.

## 기존 코드에 미치는 영향

| 파일 | 영향 |
|---|---|
| `config.py` | 거의 전부 교체. `TITLE`, `FRAGMENT_MB`, `BACKPACK_CAP_MB`, `DOCUMENTS_CAP_MB`, `HOTBAR_*`, `VIRUS_*`, `TROJAN_CHANCE` 폐기. 바이옴·결계·낮밤·습격 주기 상수 신규 |
| `items/item_kinds.py` | `mb` 필드 폐기 (슬롯 격자로 전환). 광물·재료·장비 행 대량 추가 |

| `inventory/hotbar.py` | 해금 개념 폐기, 5칸 고정 |

| `systems/` | `mining` 유지, 바이옴 생성·낮밤·습격 스케줄러·건축 신규 |

## 구현 순서 제안

각 단계는 앞 단계에 의존한다. 스펙은 단계별로 따로 쓴다.

1. **컨셉 상수 정리** — `config.py`, 아이템 카탈로그 재작성
2. **맵과 바이옴** — 중앙 초원 + 5분할 링, 거리에 따른 자원 분포
3. **코어·결계·낮밤** — 파편 수집 → 점화, 결계 반경, 결계 안 회복, 하루 주기
4. **소지품** — 슬롯 격자 UI, 배낭, 죽음 페널티
5. **자원과 제작** — 등급 사다리, 제작 시설 건축, 주조
6. **적 재분류와 습격** — 골렘/야생동물, 습격 스케줄, 주기 단축
7. **마법** — 구조물, 그림, 새김 도구, 지팡이 과부하, 탐지기
8. **보스** — 사원 5개, 고유 기믹, 레벨 캡 아이템
9. **최종전** — 최종 강화, 5회 습격, 최종 습격, 승리 화면
